# Nhật ký tiến độ Tuần 01

## Đã làm
- Xác định bối cảnh, mục tiêu và phạm vi đề tài.
- Phân tích hiện trạng quy trình phân ca.
- Xác định actor, chức năng và các quy tắc nghiệp vụ chính.
- Tìm hiểu công nghệ ASP.NET MVC, SQL Server, Entity Framework và OR-Tools.

## Đang vướng
- Chưa hiểu rõ cách áp dụng OR-Tools vào bài toán phân ca.
- Chưa hiểu rõ Entity Framework Code First và migration.
- Chức năng thêm nhân viên chưa lưu đúng dữ liệu vào SQL Server.

## Kế hoạch tuần tới
- Hoàn thiện yêu cầu chức năng và phi chức năng.
- Xây dựng Use Case Diagram.
- Sửa chức năng thêm nhân viên.
- Tiếp tục tìm hiểu Entity Framework và OR-Tools.
