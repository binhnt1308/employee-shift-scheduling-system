# Frontend Documentation

Frontend hiện được triển khai bằng Razor View và Bootstrap 5, tích hợp trực tiếp trong project ASP.NET Core MVC tại:
- `src/backend/ShiftScheduling/Views` (giao diện Razor Views, layouts, partial views)
- `src/backend/ShiftScheduling/wwwroot` (tài nguyên tĩnh: CSS, JavaScript, thư viện giao diện)

Thư mục frontend độc lập này được duy trì để sẵn sàng mở rộng hoặc tách riêng giao diện sang Single Page Application (Next.js / React / Vue) trong tương lai nếu có yêu cầu phát triển tiếp theo.
